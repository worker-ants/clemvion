# PLAN 문서 라이프사이클 (폐기)

> NERV 정본 전환 단계 3(NERV Task `CLE-T-FN2JWK`, 2026-10-01)에서 저장소 `plan/` 을 지웠다. 작업 추적의 정본은 NERV Task 다.
> 이 문서에 있던 옛 규칙(폴더 구조 · 이동 규칙 · frontmatter 스키마 · Gate C · audit 도구)은 git 이력에 있다
> (`git log --follow -- .claude/docs/plan-lifecycle.md`).
>
> 이 파일을 남겨 두는 이유는 두 가지다.
>
> - 동결된 옛 `spec/<영역>/` 트리(`spec/conventions/spec-impl-evidence.md` · `review-citations.md`)가 이 경로를 링크한다.
>   그 트리를 지우는 단계 5(NERV Task `CLE-T-7M4C4X`)에서 이 파일도 지운다.
> - NERV 스펙 `CLE-ENG-SPECEVIDENCE` · `CLE-ENG-REVIEWCITE` 의 승인본이 이 파일의 옛 절을 근거로 인용한다. 그 인용을 걷는
>   초안(단계 3 에서 저장, 사람 승인 대기)이 승인되면 이 이유는 없어진다.
>
> 새 문서는 이 파일을 링크하지 않는다.
