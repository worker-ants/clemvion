이 페이지에서는 비밀번호를 바꾸는 방법과, 변경 시 다른 기기의 세션이 어떻게 처리되는지 설명해요.

## 비밀번호 변경하기

<ImplAnchor
  kind="ui-entry"
  file="codebase/frontend/src/app/(main)/w/[slug]/profile/change-password/page.tsx"
  symbol="ChangePasswordPage"
  describes="프로필 → 비밀번호 변경 페이지 진입점"
/>

[프로필 → 비밀번호 변경](/profile/change-password) 페이지에서 진행해요. 보안 설정(2FA · Passkey)은 [프로필 → 보안](/profile/security) 에서 따로 관리해요.

<Steps>
<li>

[프로필 → 비밀번호 변경](/profile/change-password) 으로 이동해요.

</li>
<li>

**현재 비밀번호** 를 입력해요. 입력한 비밀번호가 일치해야 다음 단계로 넘어갈 수 있어요.

</li>
<li>

**새 비밀번호** 를 입력해요. 아래 정책을 모두 충족해야 해요.

- 최소 8자
- 영문 소문자 · 영문 대문자 · 숫자 · 특수문자 중 **3종 이상** 포함

</li>
<li>

새 비밀번호를 한 번 더 입력해 확인한 뒤 **변경** 을 눌러요.

</li>
</Steps>

변경이 완료되면 현재 브라우저는 로그아웃 없이 그대로 유지되고, 프로필 페이지로 돌아와요.

## 다른 기기의 세션은 어떻게 되나요?

비밀번호 변경에 성공하면 **현재 사용 중인 기기를 제외한 다른 모든 기기·세션이 즉시 로그아웃** 돼요.

분실한 기기나 의심스러운 세션을 한 번에 끊고 싶을 때 비밀번호 변경을 활용할 수 있어요. 현재 브라우저의 로그인 상태는 유지되므로 변경 직후에도 계속 작업할 수 있어요.

<Callout type="note">
  세션 관리에서 개별 세션을 직접 종료하고 싶다면 [프로필 → 세션](/profile/sessions) 에서 확인할 수 있어요.
</Callout>

<Callout type="note">
  **실시간 연결(워크플로 실행 화면 등)은 따로 신경 쓰지 않아도 돼요.** 로그인 상태가 갱신될 때
  자동으로 다시 연결되므로 화면이 끊기지 않아요.

  다만 다른 기기를 로그아웃시킨 경우, 그 기기에서 열려 있던 실시간 화면은 **최대 15분 안에**
  연결이 끊겨요 — 즉시는 아니에요.
</Callout>

## 로그인 뒤 원래 화면으로 돌아오기

로그인하지 않은 채 앱의 특정 화면 주소를 열거나 세션이 끝나면 [로그인](/login) 화면으로 이동해요. 로그인하면 원래 열려던 화면으로 돌아와요. 비밀번호와 2단계 인증으로 로그인할 때 모두 그래요. Google · GitHub 로그인은 로그인을 시작한 같은 탭에서 마치면 원래 화면으로 돌아와요.

앱 밖의 주소로는 이동하지 않아요. 돌아갈 화면을 확인할 수 없으면 대시보드가 열려요.

## 비밀번호가 없는 계정 (소셜 로그인 전용)

Google · GitHub 등 소셜 로그인(OAuth)으로만 가입한 계정은 비밀번호가 설정되어 있지 않아요. 이 경우 비밀번호 변경 페이지에서 현재 비밀번호 확인 단계를 통과할 수 없어, *"비밀번호가 설정되지 않은 계정이에요"* 안내를 받아요.

**비밀번호를 추가할 수는 있어요.** [비밀번호 찾기](/forgot-password) 에서 가입 이메일로 재설정 메일을 받아 새 비밀번호를 설정하면 돼요 — 소셜 로그인 계정도 똑같이 동작해요. 설정한 뒤에는 이메일 · 비밀번호로도 로그인할 수 있고, 이후부터는 비밀번호 변경 페이지도 정상적으로 쓸 수 있어요.

소셜 로그인 연결은 그대로 유지돼요.

## 프로필 이미지(아바타) 바꾸기

<ImplAnchor
  kind="component"
  file="codebase/frontend/src/app/(main)/w/[slug]/profile/components/profile-info-card.tsx"
  symbol="ProfileInfoCard"
  describes="프로필 사용자 정보 카드의 아바타 편집 영역"
/>

[프로필](/profile) 의 사용자 정보 카드에서 아바타를 올리거나 바꾸고 지울 수 있어요.

<Steps>
<li>

카드 오른쪽 위의 **편집** 을 눌러요. 아바타 편집 영역이 열려요.

</li>
<li>

**이미지 올리기** 로 파일을 골라요. png · jpg · jpeg · webp · gif 이미지를 최대 2MB까지 올릴 수 있어요. 고르면 미리보기가 보여요. 빈 파일이나 다른 형식, 2MB가 넘는 파일은 고르는 즉시 카드 안에 오류 문구가 표시되고 선택되지 않아요.

</li>
<li>

파일을 올리는 대신 이미지 URL 칸에 외부 이미지 주소를 넣을 수도 있어요. 주소는 `http://` 또는 `https://` 로 시작하고 500자 이하여야 해요.

</li>
<li>

아바타를 지우려면 **제거** 를 눌러요. 아바타가 있을 때만 보이는 버튼이에요. 아바타가 없으면 이름의 이니셜이 대신 표시돼요. 이미지를 불러오지 못할 때도 이니셜이 표시돼요.

</li>
<li>

**저장** 을 누르면 변경 전과 후를 비교하는 확인 창이 한 번 열려요. 확인하면 저장돼요. **취소** 를 누르면 고른 이미지와 입력한 내용이 버려져요.

</li>
</Steps>

서버가 이미지를 받지 않으면(형식이나 크기 문제) 오류 알림이 표시되고 편집 상태가 그대로 유지돼요. 파일을 바꿔 다시 저장할 수 있어요.

<Callout type="warn">
  올린 이미지는 **주소를 아는 사람이면 누구나** 볼 수 있어요. 워크스페이스 멤버에게만 공개되지 않아요. 주소에는 추측하기 어려운 값이 들어가지만, 공개하고 싶지 않은 이미지는 올리지 않는 것이 좋아요.
</Callout>

<Callout type="note">
  화면 왼쪽 아래 사이드바의 사용자 영역에도 아바타 이미지가 표시돼요. 이미지가 없거나 불러오지 못하면 이름의 이니셜이 보이고, 이름이 없으면 이메일의 첫 글자가 보여요. 프로필에서 이름이나 아바타를 저장하면 새로 고치지 않아도 사이드바에 바로 반영돼요.
</Callout>

## 이메일 변경하기

<ImplAnchor
  kind="ui-entry"
  file="codebase/frontend/src/app/(main)/w/[slug]/profile/change-email/page.tsx"
  symbol="ChangeEmailPage"
  describes="프로필 → 이메일 변경 페이지 진입점"
/>

[프로필](/profile) 화면의 사용자 정보에서 이메일 옆 **변경하기** 를 누르면 [이메일 변경 페이지](/profile/change-email) 로 이동해요.

<Steps>
<li>

[프로필 → 이메일 변경](/profile/change-email) 으로 이동해요.

</li>
<li>

**새 이메일 주소** 를 입력해요.

</li>
<li>

본인 확인을 위해 **현재 비밀번호** 또는 **2FA 코드** 를 입력해요.

</li>
<li>

**확인 메일 보내기** 를 눌러요. 입력한 새 이메일 주소로 확인 메일이 발송돼요.

</li>
<li>

받은 확인 메일의 링크를 클릭하면 이메일 변경이 확정돼요. 확정은 현재 로그인된 세션에서만 처리돼요.

</li>
</Steps>

### 변경 확정 후 세션 처리

이메일 변경이 확정되면 **현재 사용 중인 기기를 제외한 다른 모든 기기·세션이 즉시 로그아웃** 돼요. 비밀번호 변경 시와 동일한 보안 정책이에요.

### 기존 이메일로 발송되는 안내 메일

변경 확정과 동시에 **이전 이메일 주소** 로 "이메일이 변경되었어요" 안내 메일이 발송돼요. 본인이 요청한 변경이 아니라면 안내 메일의 링크를 통해 비밀번호를 재설정해 계정을 보호할 수 있어요.

### 진행 중인 변경 취소 또는 재발송

확인 메일을 받지 못하거나 변경을 취소하고 싶다면 [이메일 변경 페이지](/profile/change-email) 에서 **재발송** 또는 **취소** 를 선택할 수 있어요.

<Callout type="note">
  확인 링크는 발송 후 **1시간** 동안만 유효해요. 시간이 지났다면 재발송 후 새 링크를 사용해요.
</Callout>

### 이메일을 변경할 수 없는 경우

소셜 로그인(OAuth)으로만 가입해 **비밀번호가 없고 2FA도 켜 두지 않은 계정** 은 본인 확인 수단이 없어 이메일을 변경할 수 없어요. 이메일 변경을 원한다면 먼저 [비밀번호 찾기](/forgot-password) 에서 비밀번호를 설정한 뒤 진행해요.

<Callout type="tip">
  2FA를 먼저 켜는 방법은 쓸 수 없어요. TOTP를 켜려면 계정 비밀번호를 한 번 더 확인해야 하므로 비밀번호가 없는 계정은 켤 수 없어요. 켜는 순서는 [2단계 인증](/docs/07-workspace-and-team/security-2fa) 에서 확인해요.
</Callout>
