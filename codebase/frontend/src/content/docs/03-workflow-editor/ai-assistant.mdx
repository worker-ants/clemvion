이 페이지에서는 캔버스 안에 내장된 **AI 어시스턴트**가 무엇이고, 어떻게 여닫는지, 어떤 흐름으로 워크플로우를 만들거나 고쳐 주는지를 정리해요. 실제로 자연어로 요청을 던져 4-노드 자동화를 완성하는 시연은 [Walkthrough](/docs/03-workflow-editor/ai-assistant-walkthrough)에서 이어져요.

## 한 문장으로 요약

AI 어시스턴트는 **자연어 요청을 받아 노드와 연결선을 직접 만들어 주는 채팅형 도우미**예요. "주문 취소 프로세스 추가해줘" 같은 모호한 요청도 명확화 → 계획 제안 → 실행 3단계로 풀어 가며, 각 단계에서 사용자가 개입할 수 있게 멈춰 세워요.

## 어디에 있고 어떻게 여나요?

- **위치**: 워크플로우 에디터 우측에 도킹된 360px 패널이에요. 노드를 클릭하면 보이는 설정 패널과 같은 자리를 쓰므로, 어시스턴트를 열면 노드 선택이 풀리고 어시스턴트가 닫히면 다시 설정 패널을 열 수 있어요.
- **단축키**: `Cmd/Ctrl + /` 가 어시스턴트 패널을 켜고 끄는 토글이에요. 캔버스 어디서든 동작해요.
- **기본 상태**: 닫힘. 패널을 처음 열면 빈 화면 안내가 나와요.

<Callout type="note">툴바에 별도 버튼은 두지 않았어요. 단축키 한 번이면 어디서든 어시스턴트를 부를 수 있어요.</Callout>

### 빈 화면 안내

처음 패널을 열면 다음 안내가 보여요.

- 제목: "무엇을 도와드릴까요?"
- 서브: "자연어로 원하는 워크플로우를 설명하면 함께 만들어드려요."
- 예시 버튼 4개 — 한 번 누르면 자동으로 메시지로 채워져요.
  - "주문 취소 프로세스 추가해줘"
  - "HTTP 노드에 Authorization 헤더 추가"
  - "현재 워크플로우를 검토하고 개선점 제안해줘"
  - 그 외 1건 (배치 정리 예시)

### Plan 카드 UX

② 단계에서 계획 카드는 다음 요소로 구성돼요.

- **제목**과 **요약** — 무엇을 만들지 한 줄로 정리해요.
- **단계 체크박스 리스트** — 각 단계는 처음에 ◯(대기)로 표시되고, 실행되면 ✓(완료, 초록)로, 실패하면 ⚠(빨강)로 바뀌어요.
- **답변이 필요한 항목** — 어시스턴트가 추가 결정을 사용자에게 맡길 때 호박색 안내 박스로 질문을 보여줘요. 답은 **하단 메시지 입력창**에 평소처럼 적어 보내면 돼요. 별도 답변 폼은 없어요.
- **"계획대로 진행" 버튼** — 사용자가 누르면 ③ 단계가 시작돼요. 누르기 전엔 캔버스가 변하지 않아요.

<Callout type="tip">
계획에 동의하기 어려운 부분이 있다면 승인 버튼 대신 채팅으로 "X를 빼고 Y를 더 넣어 줘" 처럼 보내요. 어시스턴트가 새 계획 카드로 교체해서 다시 제시해요.
</Callout>

## 세션과 영속성

어시스턴트의 대화는 **워크플로우 단위로 한 세션**이 만들어져요. 세션은 서버에 저장되므로 페이지를 새로고침하거나 다른 기기에서 접속해도 이어서 쓸 수 있어요.

- **자동 생성** — 첫 메시지를 보내면 세션이 자동으로 만들어져요. 빈 패널에서 `+` 버튼으로 새 세션을 만들 수도 있어요.
- **자동 제목** — 첫 사용자 메시지의 앞부분으로 세션 제목이 자동으로 생성돼서 패널 헤더에 작은 글씨로 보여요.
- **이력 보관** — 한 워크플로우당 최근 세션 50개까지 보관돼요. v1에서는 패널 안에 세션 전환 UI가 노출되지 않으므로, 같은 워크플로우의 이전 세션을 다시 열려면 `+`로 새 세션을 만들거나 자동 복원되는 가장 최근 세션을 그대로 이어가요.
- **다른 사용자와 공유 안 됨** — 세션은 개인 단위예요. 팀 워크스페이스의 다른 멤버는 자기 세션을 따로 가져요.

## 모델 선택

패널 상단의 **모델** 드롭다운으로 세션 도중에도 LLM 프로바이더를 바꿀 수 있어요. 기본값은 워크스페이스에 등록한 LLM 설정 중 우선순위가 높은 항목이에요. 모델을 바꾸면 다음 메시지부터 적용돼요. LLM 설정 등록은 [모델 설정](/docs/06-integrations-and-config/models)에서 다뤄요.

## 실행 결과로 진단·수정하기

어시스턴트는 직접 실행하지 못하지만, **사용자가 `Run` 으로 실행한 결과**를 읽고 어디서 무엇이 잘못됐는지 짚어 줄 수 있어요.

<Steps>
<Step>실행이 끝난 뒤 어시스턴트에 "왜 실패했어?" 또는 "Lead Router 노드 결과 확인해 줘" 처럼 물어요.</Step>
<Step>어시스턴트가 최근 실행 목록과 상세 타임라인을 조회해 실패한 노드와 직전 노드의 입출력을 확인해요. (민감 필드는 자동으로 마스킹돼요.)</Step>
<Step>원인이 짚이면 수정 계획 카드를 띄워요. 사용자가 승인하면 노드 설정을 패치해요.</Step>
<Step>사용자가 다시 `Run` 버튼을 눌러 결과를 확인해요.</Step>
</Steps>

## 자주 만나는 오류

| 상황 | 화면에 보이는 메시지 | 사용자 조치 |
| --- | --- | --- |
| 사용할 모델 설정이 없을 때 (패널에서 고른 설정도, 워크스페이스 기본 모델도 없음) | 빨간 오류 박스에 `ASSISTANT_NO_LLM_CONFIG` 라벨과 "사용할 모델 설정이 없어요. 모델 설정 화면에서 Chat 모델을 먼저 등록해 주세요." 안내가 나오고 그 아래에 "모델 설정으로 이동" 링크가 붙어요 | 링크를 누르면 [모델 설정](/docs/06-integrations-and-config/models)의 Chat 탭이 열려요. 거기서 Chat 모델을 등록한 뒤 메시지를 다시 보내요 |
| 패널에서 고른 모델 설정이 삭제됐을 때 | 삭제된 설정이 계속 선택된 채로 패널이 열려 있으면, 워크스페이스 기본 모델이 있어도 위와 같은 `ASSISTANT_NO_LLM_CONFIG` 오류 박스가 나와요. 페이지를 새로고침하면 삭제된 설정의 선택이 풀리고 별도 안내 없이 워크스페이스 기본 모델이 쓰여요 | 패널 상단 모델 드롭다운에서 다른 설정을 골라 다시 보내거나 페이지를 새로고침해요. 기본 모델도 없으면 위 행처럼 Chat 모델을 먼저 등록해요 |
| 프로바이더 요청 한도 초과 (rate limit) | Anthropic · Google AI 모델은 빨간 오류 박스에 `LLM_RATE_LIMIT` 라벨과 "AI 모델의 요청 한도를 넘었어요. 잠시 후 같은 메시지를 다시 보내 주세요." 안내가 나와요. OpenAI 계열(OpenAI · Azure OpenAI · Local)은 응답이 오기 시작한 뒤에 한도에 걸릴 때만 같은 안내가 나오고 응답이 오기 전에 걸리면 아래 「응답이 없거나 늦어질 때」 오류로 표시돼요 | 잠시 기다린 뒤 같은 메시지를 다시 보내요. 이 오류에는 재시도 버튼도 "이어서 진행" 버튼도 없어요 |
| 응답이 없거나 늦어질 때 (응답 없음 · 응답 지연 · 시간 초과) | 빨간 오류 박스에 `ASSISTANT_STREAM_FAILED` 라벨과 "AI 모델의 응답을 받지 못했어요. 요청 한도를 넘었거나 응답이 늦어졌을 수 있어요. 잠시 후 같은 메시지를 다시 보내 주세요." 안내가 나와요. OpenAI 계열(OpenAI · Azure OpenAI · Local)은 요청 한도 초과를 포함해 응답이 오기 전에 난 오류가 모두 이렇게 표시돼요 | 잠시 기다린 뒤 같은 메시지를 다시 보내요. 이 오류에는 재시도 버튼이 없어요 |
| 응답을 받는 도중 연결이 끊겼을 때 | 빨간 오류 박스에 `LLM_CONNECTION_ERROR` 라벨과 "AI 모델과 통신하다가 오류가 났어요. 잠시 후 같은 메시지를 다시 보내 주세요." 안내가 나와요. Anthropic · Google AI는 요청 한도 초과가 아닌 이유로 응답이 오기 전에 요청이 실패해도 같은 안내가 나와요 | 같은 메시지를 다시 보내요 |
| 도구 호출 실패 | 메시지 아래 빨간 배지에 코드와 짧은 설명 | 어시스턴트가 다음 턴에 자동으로 다시 시도해요. 반복 실패 시 사용자가 직접 노드를 수정하거나 다른 접근을 지시해요. |
| 한 턴의 도구 호출 한도 초과 | 빨간 오류 박스에 `ASSISTANT_TOO_MANY_TOOL_CALLS` 라벨이 나오고 같은 박스 안에 "이어서 진행" 버튼이 붙어요. 이 버튼이 붙는 오류는 이것 하나뿐이에요 | 버튼을 누르면 남은 단계가 다음 턴에서 이어져요 |
| 대화 세션이 다른 곳에서 삭제됐을 때 | 메시지를 보내면 화면에 짧은 오류 알림이 잠깐 나타나고 답변은 오지 않아요. 새 대화가 자동으로 시작되지는 않아요 | 패널 헤더의 `+` ("새 대화 시작") 버튼으로 새 대화를 시작한 뒤 메시지를 다시 보내요 |

## 팁 & 참고

- 실제 사용 흐름은 [Walkthrough](/docs/03-workflow-editor/ai-assistant-walkthrough) 에서 자연어 한 줄로 4-노드 워크플로우를 완성하는 과정을 단계별로 따라가요.
- AI 어시스턴트와 [AI Agent 노드](/docs/02-nodes/ai)는 별개예요. **어시스턴트는 에디터 안의 도우미**이고, **AI Agent 노드는 워크플로우 안에서 실행되는 LLM 호출 단위**예요. 어시스턴트가 만들어 주는 결과물 안에 AI Agent 노드가 포함될 수도 있어요.
- 어시스턴트가 만든 변경은 일반 편집과 같은 Undo 스택에 들어가요. 마음에 들지 않으면 `Ctrl+Z` 로 되돌리고 다시 지시하세요.
- 도구가 무엇을 했는지 항상 메시지 아래 배지로 표시되니, 어시스턴트의 행동이 의심스러우면 배지를 확인해요.
