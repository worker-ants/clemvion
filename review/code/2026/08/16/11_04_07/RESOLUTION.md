## W1 (requirement) — **네 번째로 같은 뿌리다.** 내가 좁힌 문장이 아직도 넓었다 · **반영**

전 라운드에서 `sanitizeErrorMessage` docstring 의 과장("WS 이벤트 보호")을 좁히면서
*"호출부 3곳 전부 알림 조립 지점"* 이라고 썼다. 그것도 틀렸다. 실측:

```
background-execution.processor.ts:70-77
  const message = sanitizeErrorMessage(err);
  …
  this.safeEmitRunCompleted(data, 'failed', runStartedAt, message);   ← WS 에도 싣는다
  if (data.config.notifyOnFailure) await this.dispatchFailureNotification(data, message);
```

**알림 전용이 아니다.** 다만 그 WS 는 `background:run:<id>` 로 **격리된 내부 채널**이고
SSE/webhook 으로 나가지 않는다 — 종결 3종의 외부 노출과는 다른 표면이라 안전성 결함은 아니다.

→ 호출부를 **표로 분해**해 각각 무엇에 쓰는지 적었다. "전부 …" 같은 총칭이 이 파일에서 두 번
연속 틀렸으므로, 이번엔 열거로 바꾼다.

> **이 브랜치에서 같은 뿌리가 네 번이다** — 마스킹 범위(`09_51_00`) → 검증 범위(`10_19_30`)
> → 주석 범위(`10_41_55`) → **정정한 주석의 범위**(이번). 매번 "전부/모두" 를 실측 없이 썼다.
