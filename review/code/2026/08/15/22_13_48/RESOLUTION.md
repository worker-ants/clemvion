### INFO2 (testing) — export-default 캐너리가 별칭 형태를 못 본다 · **후속 등재**

`export { X as default } from '…'` 을 새 캐너리가 판정하지 못한다. 사실이다.

다만 **실제 우회로는 없다** — 리뷰어도 그렇게 적었고 나도 확인했다. 캐너리는 "대상 모듈에
default export 가 있는가" 를 보는 자기점검이고, 진짜 방어선은 세 번째 테스트다. 누가
`import D from '…/websocket.service'` 로 끌어오면 default 바인딩이 값 간선으로 잡힌다
(형태별 전수 뮤테이션의 "default 단독" 이 RED 로 실증).

즉 **방어는 완전하고 캐너리만 좁다.** 지금 고치면 `codebase/**` 가 또 바뀌어 8라운드를 돌아야
하는데, 얻는 것은 자기점검의 완전성뿐이다. plan 후속으로 등재한다.

### INFO3 (maintainability) — `ts.getModifiers(st as ts.HasModifiers)` 캐스트 · **후속 등재**

`ts.canHaveModifiers(st)` 가드로 대체하면 캐스트가 불필요하다. 순수 스타일이고 런타임 위험이
없다. INFO2 와 같은 이유로 후속.
