## cross_spec — spec 이 실제 동작을 잘못 서술하고 있었다

`§1` 이 두 입력 경로를 상호배타로 서술했는데, 실제로는 **정상 임베드에서 둘 다 순차 발동**한다
(SDK 가 iframe src 쿼리에 싣고 → 위젯이 그 값으로 먼저 부팅 시도 → `wc:boot` 이 세대 판정으로
대체). 이 오서술을 믿고 쿼리 폴백을 "샘플 전용" 으로 제거하면 **모든 정상 임베드가 깨진다** —
그 위험을 표에 명시했다.

이건 이 PR 이 시작할 때의 문제와 같은 형태다: **문서가 두 경로를 다르게 취급한다고 적어 놓고,
코드는 둘 다 같은 값을 흘리고 있었다.**
