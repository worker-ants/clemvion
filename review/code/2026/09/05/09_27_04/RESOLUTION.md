### 고쳤다는 것을 렌더 diff 로 확인했다

처음 만든 검증 프로브 두 개(*"부록 B 헤더가 보이나"*, *"DROP-먼저 본문이 코드블록 밖인가"*)는
**전후를 못 갈랐다** — 둘 다 before/after 값이 같았다. 그 상태로 "고쳤다" 고 적을 뻔했다.

렌더된 HTML 을 직접 diff 해서 갈랐다:

```
- </code></pre>
- <p><strong>0) 이 없으면 재실행이 인덱스를 0개로 만든다.</strong> ...   ← 코드블록을 탈출해 HTML 로
+ ```
+ **0) 이 없으면 재실행이 인덱스를 0개로 만든다.** ...                    ← 블록 안 리터럴로 유지
```

부록 A 는 README 에 **붙여 넣을 마크다운 원문**을 보여 주는 자리이므로, 그 안의 볼드·헤더가
렌더돼 버리면 목적이 무너진다. 고친 뒤 리터럴로 남는다.
