PATCH cron → nextRunAt 재계산', ...)` 블록)와 대조 확인했다.

- 인증은 기존 `authHeaders()` 헬퍼를 그대로 재사용 — 신규 인증/인가 로직 없음
- 서비스 코드(`schedules.service.ts`), 라우팅, DB 쿼리, 시크릿 관리, 암호화, 에러 처리 경로는 이 diff 에 전혀 포함되지 않음
