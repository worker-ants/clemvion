  정의화 근거, `parseWhereRefs`의 `residue` 검사 이유) — 코드 동작과 정확히 일치하는지
  직접 대조했다. `residue`는 `head.replace` 로 매치된 참조를 제거한 나머지에서 공백·가운뎃점을

  정확히 대응한다. 신규 대조군 3건(`[대조군] 구분자를 · 가 아닌 것으로…`,
  `[대조군] 등록된 항목의 where 는 전부 잔여가 없다`, `[루트 통일] packages 에만 있는
  파일도 특정된다`)도 각각 서술한 판별 지점(다른 구분자, 정상 표기, 라운드-종속 basename)을
